# 📖 Project Overview

**Al Quran Multilingual** is a **completely free, ad-free, privacy-first, open-source Quran study platform** created by **Jinosh Nadar**.
It offers:

* **470+ authentic Quran translations & tafsir**
* **90+ languages**
* **Offline access**
* **Side-by-side multilingual view (unique in the world)**
* **Beautiful typography and smart reading tools**
* **Native apps + full web version**

### 🌍 Why this project is unique

✔️ **World’s only platform** with **470+ Quran editions** available for *free download*
✔️ **World’s only native app** that can display **all 90+ languages/translations on a single page**
✔️ **No ads, no trackers, no login, no data collection**
✔️ **Works across 5 platforms** (Web, Android, iOS, Windows, macOS, Linux)

# 🔗 Main Website Pages & Routes

### Core Pages

* 🏠 Home: `/`
* 🌍 Languages: `/books`
* 📥 Download: `/download`
* 📝 Blog: `/blog`
* ℹ️ About: `/about`
* ✉️ Contact: `/contact`
* 💝 Donate: `/donate`
* 🔐 Privacy Policy: `/policy`

### Dynamic Routes

* **Full Book Reader:** `/books/:editionCode/read`
* **PDF Download:** `/books/:editionCode/download_pdf`
* **Combined PDF:** `/combined-quran`
* **Direct Dual Language:** `/combined-quran/:left/:right`
* **Verse Reader:** `/book/:editionCode/:chapter/:verse`
* **Chapter View:** `/book/:editionCode/:chapter`
* **Surah List:** `/chapters/:editionCode`

# 🛠 Technical Stack

### **Frontend**

* React 18 + TypeScript
* Vite
* Tailwind CSS (HSL)
* shadcn/ui + Radix UI
* TanStack Query
* React Hook Form + Zod
* Lucide Icons

### **Performance**

* Route-based code splitting
* PWA offline architecture
* Minimal fonts
* Highly optimized bundle size

### **Backend / Infrastructure**

* FastAPI backend
* Firebase Analytics
* Google Analytics
* Hosted on Lovable (Netlify infra)
